# loc.footnotes


Target the footnotes section of the footer.


Usage

``` python
loc.footnotes()
```


With [loc.footnotes()](loc.footnotes.md#great_tables.loc.footnotes), we can target only the footnotes in the table's footer. This is useful when applying custom styling with the <a href="../reference/GT.tab_style.html#great_tables.GT.tab_style" class="gdls-link"><code>tab_style()</code></a> method. That method has a `locations=` argument and this class should be used there to perform the targeting. The 'footnotes' location is generated by <a href="../reference/GT.tab_footnote.html#great_tables.GT.tab_footnote" class="gdls-link"><code>tab_footnote()</code></a>. To target both the footnotes and source notes sections together, use <a href="../reference/loc.footer.html#great_tables.loc.footer" class="gdls-link"><code>loc.footer()</code></a> instead.


## Returns


`LocFootnotes`  
A `LocFootnotes` object, which is used for a `locations=` argument if specifying the footnotes section.


## Examples

Let's use a subset of the [gtcars](data.gtcars.md#great_tables.data.gtcars) dataset in a new table. We'll add a footnote (with <a href="../reference/GT.tab_footnote.html#great_tables.GT.tab_footnote" class="gdls-link"><code>tab_footnote()</code></a>) and a source note, then style only the footnotes section inside <a href="../reference/GT.tab_style.html#great_tables.GT.tab_style" class="gdls-link"><code>tab_style()</code></a> with `locations=loc.footnotes()`.


``` python
from great_tables import GT, style, loc
from great_tables.data import gtcars

gtcars_mini = gtcars[["mfr", "model", "msrp"]].head(5)

(
    GT(gtcars_mini)
    .tab_footnote(
        footnote="Prices in USD.",
        locations=loc.column_labels(columns="msrp")
    )
    .tab_source_note(source_note="From edmunds.com")
    .tab_style(
        style=style.fill(color="#FFFFDD"),
        locations=loc.footnotes()
    )
)
```

Styling footnotes separately from source notes lets you visually distinguish the two sections. Here we apply different background fills to each.


``` python
(
    GT(gtcars_mini)
    .tab_footnote(
        footnote="Prices in USD.",
        locations=loc.column_labels(columns="msrp")
    )
    .tab_footnote(
        footnote="All models from 2017.",
        locations=None
    )
    .tab_source_note(source_note="From edmunds.com")
    .tab_style(
        style=style.fill(color="#FFFFDD"),
        locations=loc.footnotes()
    )
    .tab_style(
        style=style.fill(color="#DDECFF"),
        locations=loc.source_notes()
    )
)
```
