# shiny.output_gt()

Output UI for a great_tables table.

Usage

[Source](https://github.com/posit-dev/great-tables/blob/main/great_tables/shiny.py#L104-L123)

``` python
shiny.output_gt(
    id,
    placeholder=None,
)
```

## Parameters

`id: str`  
An output id.

`placeholder: bool | None = None`  
Deprecated and has no effect. This argument was never implemented and will be removed in a future release.
