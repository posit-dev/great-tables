# GT.as_raw_html()

Get the HTML content of a GT object.

Usage

[Source](https://github.com/posit-dev/great-tables/blob/main/great_tables/_export.py#L142-L308)

``` python
GT.as_raw_html(
    inline_css=False,
    make_page=False,
    all_important=False,
    runtime="inline",
)
```

The [as_raw_html()](../reference/GT.as_raw_html.md#great_tables.GT.as_raw_html) method extracts the HTML representation of a GT table and returns it as a string. This is useful when you need to embed a table in existing HTML content, email templates, web applications, or other contexts where you need direct access to the HTML markup rather than displaying the table directly.

By default, the method returns an HTML fragment containing just the table and its associated CSS styles in a `<style>` block. However, the method provides several parameters for customizing the output format-like `inline_css=`, `make_page=`, and `all_important=`.

Body cells that have not been processed by a `fmt_*()` method are automatically HTML-escaped to prevent cross-site scripting (XSS). Cells that have been formatted (e.g., with [`fmt_number()`](../reference/GT.fmt_number.md#great_tables.GT.fmt_number), [`fmt_markdown()`](../reference/GT.fmt_markdown.md#great_tables.GT.fmt_markdown), etc.) are trusted as safe HTML. To include raw HTML in unformatted cells, use the [html()](../reference/html.md#great_tables.md) helper (e.g., `html("<b>bold</b>")`) via a `fmt_*()` method or [text_transform()](../reference/GT.text_transform.md#great_tables.GT.text_transform).

## Parameters

`inline_css: bool = False`  
If `True`, all CSS styles are inlined into the HTML elements as `style` attributes, with literal values for the table's mode (`"auto"` gives the light table). Use it for email and for older renderers: the default `<style>` block is written with CSS custom properties, which email clients such as Gmail and Outlook and old engines such as wkhtmltopdf don't support, so they draw the table unstyled. It doesn't apply to an interactive table (one made with [`opt_interactive()`](../reference/GT.opt_interactive.md#great_tables.GT.opt_interactive)), which needs its `<style>` block and its script: it's ignored, with a warning (for a table in an email, use `opt_interactive(active=False)`).

`make_page: bool = False`  
If `True`, the table will be wrapped in a complete HTML page with proper `<html>`, `<head>`, and `<body>` tags. This is useful when you want to display the table in a web browser or save it as a standalone HTML file.

`all_important: bool = False`  
If `True`, all CSS declarations are marked with `!important` to ensure they take precedence over other styles that might be present in the document.

`runtime: Literal["inline", "none"] = "inline"`  
Whether an interactive table's HTML (a table made with [`opt_interactive()`](../reference/GT.opt_interactive.md#great_tables.GT.opt_interactive)) is followed by the runtime that makes it interactive, its JavaScript and CSS: `"inline"` (the default) or `"none"`, for a page that has the runtime once, however many tables it shows (see [`runtime_tags()`](../reference/web.runtime_tags.md#great_tables.web.runtime_tags)). A static table has no runtime, so this doesn't change it.

## Returns

`str`  
An HTML string containing the table. The format depends on the parameters passed to the method.

## Examples:

Let's use a subset of the [gtcars](../reference/data.gtcars.md#great_tables.data.gtcars) dataset to create a new table.

``` python
from great_tables import GT, data, md, style, loc
from great_tables.data import gtcars
import polars as pl

gtcars_mini = (
    data.pl.gtcars
    .select(["mfr", "model", "msrp"])
    .head(5)
)

gt_tbl = (
    GT(gtcars_mini)
    .tab_header(
        title=md("Data listing from **gtcars**"),
        subtitle=md("gtcars is an R dataset")
    )
    .tab_style(
        style=style.fill(color="LightCyan"),
        locations=loc.body(columns="mfr")
    )
    .fmt_currency(columns="msrp")
    .tab_options(
        heading_background_color="Azure",
        table_body_hlines_color="Lavender",
        table_body_hlines_width="2px"
    )
    .opt_horizontal_padding(scale=2)
)

gt_tbl
```
