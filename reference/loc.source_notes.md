# loc.source_notes

Target the source notes.

Usage

[Source](https://github.com/posit-dev/great-tables/blob/main/great_tables/_locations.py#L979-L1014)

``` python
loc.source_notes()
```

With [loc.source_notes()](../reference/loc.source_notes.md#great_tables.loc.source_notes), we can target the source notes in the table. This is useful when applying custom with the [`tab_style()`](../reference/GT.tab_style.md#great_tables.GT.tab_style) method. That method has a `locations=` argument and this class should be used there to perform the targeting. The 'source_notes' location is generated by [`tab_source_note()`](../reference/GT.tab_source_note.md#great_tables.GT.tab_source_note).

## Returns

`LocSourceNotes`  
A `LocSourceNotes` object, which is used for a `locations=` argument if specifying the source notes.

## Examples

Let's use a subset of the [gtcars](../reference/data.gtcars.md#great_tables.data.gtcars) dataset in a new table. Add a source note (with [`tab_source_note()`](../reference/GT.tab_source_note.md#great_tables.GT.tab_source_note) and style the source notes section inside [`tab_style()`](../reference/GT.tab_style.md#great_tables.GT.tab_style) with `locations=loc.source_notes()`.

``` python
from great_tables import GT, style, loc
from great_tables.data import gtcars

(
    GT(gtcars[["mfr", "model", "msrp"]].head(5))
    .tab_source_note(source_note="From edmunds.com")
    .tab_style(
        style=style.text(color="blue", size="small", weight="bold"),
        locations=loc.source_notes()
    )
)
```
