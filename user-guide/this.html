The Zen of Great Tables

Python has a well-known easter egg: import this prints The Zen of Python (PEP 20). Great Tables took inspiration from this and wrote its own Zen. And since it’s a Zen about tables, importing it in a notebook shows a great table:

import great_tables.this

At the console, the import prints the aphorisms as plain text instead, just like import this does. To see the table from there, open it in your browser:

from great_tables.this import table

table().show()
